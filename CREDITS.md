**Chris Lemke** — author of the Windows 95/98 website design reference that inspired the visual language of NoteKeep 98.

- **Original design-reference repository:** https://github.com/chrislemke/website_designs/tree/main

NoteKeep 98 draws inspiration from this reference's classic Windows 95/98 UI concepts: 3D beveled borders, system-gray controls, teal desktop, navy title bars, window chrome, and taskbar. The application code, CSS, and UI icons are an independent implementation and are not presented as Chris Lemke's work. No association, sponsorship, or endorsement is implied.
